# Настройка перекрёстного ревью

Этот каталог настраивает скил `cross-review:cross-review` для репозитория: какие модели запускать и
какие промты и линзы им давать. Его создал `/cross-review:cross-review-setup`. Закоммитьте его, чтобы
настройка была общей для команды.

## Что здесь

| Путь | Что это |
| --- | --- |
| `cross-review.json` | действующие настройки: только то, что отличается от плагина |
| `prompts/<имя>.md` | ваш промт вместо одноимённого промта плагина |
| `lenses/<имя>.md` | ваша линза: заменяет одноимённую линзу плагина или добавляет новую |
| `defaults/` | образец — дефолты плагина. Скил его не читает |
| `runs/` | данные прогонов, в git не попадают |

## Как настроить

- **Модели и уровень** — допишите нужный ключ в `cross-review.json`. Все ключи и их значения — в
  `defaults/cross-review.json`. Объекты сливаются с дефолтами, массивы (`roster`, `lenses`) заменяются
  целиком. Например, другая модель Codex на уровне `standard`:

  ```json
  {
    "tier": "standard",
    "tiers": { "standard": { "codex": "gpt-6-sol:high" } }
  }
  ```

- **Промт или линза** — скопируйте файл из `defaults/prompts/` в `prompts/` (или из `defaults/lenses/` в
  `lenses/`) и правьте копию. Плейсхолдеры `{{…}}` не удаляйте: без них промт не соберётся.
- **Новая линза** — положите `lenses/<имя>.md` и добавьте имя в `lenses` нужного агента в `roster`.
  Массив заменяется целиком, поэтому перенесите в `cross-review.json` и остальных агентов.
- **Не копируйте то, что не меняете.** Копия перекрывает файл плагина и перестаёт получать его обновления.

## Как проверить

Запустите `/cross-review:cross-review-setup` ещё раз. Он ничего вашего не перезапишет и покажет, какие
агенты пойдут на каких моделях и откуда взят каждый промт и линза — из плагина или из этого каталога.

## После обновления плагина

Запустите `/cross-review:cross-review-setup` снова: он обновит только `defaults/`. В
`git diff .cross-review/defaults/` видно, что изменилось в плагине, — перенесите нужное в свои копии в
`prompts/` и `lenses/`.

`defaults/LICENSE` — лицензия MIT промтов, линз и схем плагина.
